# Telegram и OBS

[English](TELEGRAM_SETUP.md) · **Русский**

## Обычный запуск

Закрой незавершённый предпросмотр кружка в Telegram и запусти:

```text
Start.cmd
```

Сначала откроется экран управления, а физическая камера останется закрытой.
Когда будешь готов продолжить, нажми в этом окне `Enter`.

Сценарий сам:

1. освобождает физическую камеру перед запуском;
2. ждёт настоящий кадр;
3. открывает профиль **MonkeyFacesMeme**;
4. включает OBS Virtual Camera;
5. выставляет чистый сигнал 720×720 при 30 FPS.

После этого в Telegram выбери **OBS Virtual Camera**.

## Настройки OBS

- Base Resolution: `720×720`;
- Output Resolution: `720×720`;
- FPS: `30`;
- сцена: `MonkeyFacesMeme`;
- источник: `MonkeyFacesMeme Feed`;
- окно: `MonkeyFacesMeme Output`;
- Capture Method: `BitBlt`;
- Capture Cursor: выключено;
- Scale Filtering: `Lanczos`;
- Color Space: `Rec.709`;
- Color Range: `Partial`.

Основное окно приложения работает на весь экран. Квадратное служебное окно OBS
имеет фиксированный размер и специально не разворачивается.

BitBlt нужен потому, что WGC на некоторых версиях Windows захватывает окно
OpenCV полностью чёрным.

## Что видно в кружке

Без жеста идёт только живая камера. Когда жест подтверждён, сначала видно само
движение, затем фотография плавно заполняет весь круг. Внутренних карточек,
чёрных полос и размытого фона нет.

Появление занимает `0.12` секунды. Реакция остаётся минимум на `0.95` секунды,
а затем плавно возвращается камера.

## Если кружок чёрный

1. Проверь изображение в окне `MonkeyFacesMeme Output`.
2. Открой предпросмотр сцены `MonkeyFacesMeme` в OBS.
3. Проверь, что источник использует BitBlt.
4. Нажми **Start Virtual Camera**, если камера OBS остановлена.
5. В Telegram заново выбери OBS Virtual Camera и начни новую запись.

Если чёрное уже само окно приложения, закрой программы, которые используют
физическую камеру, и запусти приложение снова.

Пути к логам текущего запуска выводятся в консоль. Логи лежат в:

```text
%LOCALAPPDATA%\MonkeyFacesMeme\logs
```

## Сохранённые файлы

- `S` создаёт `screenshots/shot_YYYYMMDD_HHMMSS_mmm.png`;
- `R` создаёт `recordings/camera_YYYYMMDD_HHMMSS_mmm_720x720.mp4`;
- `G` создаёт `screenshots/sequence_...` с последними кадрами.
