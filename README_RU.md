# MonkeyFacesMeme

[English](README.md) · **Русский**

Приложение для Windows, которое распознаёт жесты и превращает их в плавные
полноэкранные реакции с обезьянами. Для кружков Telegram есть чистый выход
720×720 через OBS Virtual Camera.

Всё работает локально. Кадры с камеры никуда не загружаются.

## Возможности

- захват встроенной или USB-камеры в 1280×720 при 30 FPS;
- распознавание тела, лица и обеих рук через MediaPipe Holistic;
- показ реакции только после подтверждения жеста;
- плавное заполнение квадратного кадра без внутренних рамок и чёрных полос;
- чистый поток 720×720 для OBS Virtual Camera;
- сохранение PNG, MP4 и последовательностей последних кадров;
- защита интерфейса от вечной блокировки внутри `capture.read()`;
- корректное закрытие через `Q`, кнопку окна или `Ctrl+C`.

## Жесты

| Реакция | Что показать |
|---|---|
| Thinking | Палец возле подбородка |
| Pointing | Указательный палец над головой |
| Shocked | Широко открыть рот |
| Snide | Соединить руки, улыбнуться и немного нахмуриться |
| Mid finger | Показать средний палец |
| Love | Сделать сердце большими и указательными пальцами |
| Power | Сжать два кулака |

Без активного жеста в кадре остаётся обычная камера.

## Быстрый старт на Windows 10/11

Сначала установи:

- Python 3.11;
- OBS Studio;
- Telegram Desktop, если нужен вывод в кружок.

После загрузки или распаковки проекта один раз запусти:

```text
Setup.cmd
```

Сценарий создаст `.venv`, установит закреплённые версии библиотек и подготовит
профиль OBS. После этого запускай приложение через:

```text
Start.cmd
```

Сначала откроется экран со всеми клавишами, а камера ещё не будет занята.
Когда будешь готов, нажми `Enter`. После запуска камеры клавиша `T` включает
или выключает чистое окно для Telegram и OBS.

Основное окно сразу открывается на весь экран. Клавиша `F` переключает полный
и оконный режимы. Для OBS используется отдельное фиксированное окно 720×720,
поэтому размер основного интерфейса не влияет на Telegram-кружок.

Ручной запуск без OBS:

```powershell
.\.venv\Scripts\python.exe main.py
```

Ручной запуск с квадратным выходом и OBS:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start_telegram.ps1
```

В Telegram выбери **OBS Virtual Camera**.

## Управление

| Клавиша | Действие |
|---|---|
| `Q` | Закрыть приложение |
| `T` | Включить или выключить чистый квадратный выход |
| `S` | Сохранить PNG в `screenshots` |
| `R` | Начать или завершить запись MP4 в `recordings` |
| `G` | Сохранить последние кадры отдельной последовательностью |
| `P` | Пауза |
| `C` | Переключить камеру |
| `H` | Показать помощь |
| `N` | Включить или выключить плавные переходы |
| `F` | Полноэкранный режим |

Имена файлов содержат дату, время и миллисекунды, поэтому существующие записи
не перезаписываются.

Горячие клавиши работают с Caps Lock и в русской раскладке. Файлы всегда
сохраняются в `screenshots` и `recordings` рядом с `main.py`.

## Надёжная работа камеры

Приложение проверяет индексы `0`, `1`, `2`: для каждого сначала DSHOW, затем
MSMF. Камера принимается только после настоящего непустого изображения. Захват
идёт в отдельном процессе, поэтому зависший драйвер останавливается по тайм-ауту
и не блокирует интерфейс.

MediaPipe получает уменьшенную копию для анализа, а приложение и OBS сохраняют
исходные пиксели. Фотографии реакций подготавливаются один раз и хранятся в
памяти, поэтому переходы работают плавно.

Настройка OBS и решение проблемы чёрного экрана описаны в
[TELEGRAM_SETUP_RU.md](TELEGRAM_SETUP_RU.md).

## Структура проекта

```text
main.py                  короткая точка запуска
monkeyfacesmeme/         камера, жесты, медиа, интерфейс и жизненный цикл
memes/                   фотографии реакций
```

## Проверка

```powershell
.\.venv\Scripts\python.exe -m compileall -q main.py monkeyfacesmeme
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -c "import cv2, mediapipe, numpy; print('Imports OK')"
```

Рабочие версии закреплены в `requirements.txt`:

```text
numpy==1.26.4
mediapipe==0.10.9
opencv-contrib-python==4.11.0.86
```

## Приватность

В приложении нет сервера, аналитики, телеметрии, аккаунтов и сетевых API.
Кадры остаются на компьютере, пока пользователь сам их не сохранит или не
начнёт трансляцию.
